# Research Series: Industrial Simulation Software (Shouchun Wu)

One independent repository per paper, numbered by paper order (`paperNN-<topic>`).
Every paper repo carries: tagged dataset releases (`vX.Y.Z` + `CHANGELOG.md`), `CITATION.cff`,
and a series header in its README. This profile README is the series index.

## Conventions

- **One repo per paper**, named `paperNN-<topic>`, indexed here in submission order.
- **Dataset versioning**: semantic tags (`vX.Y.Z`); any post-release value change ships a new tag + `CHANGELOG.md` entry; released values are never rewritten silently.
- **Citation**: each repo ships `CITATION.cff`; cite the paper, then the replication package.
